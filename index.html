RUANG EKSPERIMEN

Git Playground

Mulai dari folder rumah, buat folder project, lalu ikuti alur Git langkah demi langkah. Semua perintah di sini hanya simulasi.

🛡️ SIMULASI AMAN
terminal — ~ (folder rumah)
Kamu sedang berada di folder rumah ~. Pertama, buat folder project dengan mkdir belajar-git, lalu masuk dengan cd belajar-git.
LANGKAH AWAL:
ALUR LATIHANDari folder kosong ke commit pertama
  1. mkdir belajar-gitBuat folder project.
  2. cd belajar-gitMasuk ke folder itu.
  3. pwdPastikan lokasimu benar.
  4. git initMulai riwayat Git.
  5. touch README.mdBuat file latihan.
  6. git statusPeriksa perubahan.
  7. git add .Pilih file untuk disimpan.
  8. git commit -m "Menambahkan README"Simpan catatan pertama.
  9. git remote add origin URL_REPOSITORYHubungkan alamat GitHub.
  10. git push -u origin mainKirim commit ke remote.
💡 Jangan langsung mengetik git init dari folder rumah. Pastikan kamu sudah cd belajar-git dahulu.
